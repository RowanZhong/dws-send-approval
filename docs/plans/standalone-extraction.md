# 独立项目抽离方案与交付记录

2026-09-27 · 助手 0.8.0

## 范围

以两版原有 0.7.0 助手相同的业务源码为基础，独立维护一份插件。监听、身份发现、主题识别、无工具拟稿、本人审批、固定模板自动回复与通知逻辑沿用。插件 ID、配置项、状态目录和 SQLite 数据结构保持兼容。模板文件保持原样。

旧宿主继续使用原兼容 Channel 分支。新宿主使用上游锁定基线加通用接口最小补丁，上游接受接口后移除过渡补丁。既有三个社区能力增强不属于助手依赖，不带入新版补丁。具体版本和校验值见 `../../compat/manifest.json`。

## 卡片适配

`card-transport.mjs` 是唯一传输选择入口。通用接口客户端随包提供，使用与 Channel 相同的进程内注册表，不额外安装或启动 Channel。公共接口已提供时优先使用，即使暂时断线也不降级重发。没有公共接口时使用原桥接。

数据库中的逻辑卡片 ID 不变；通用接口使用 `ocx1.<account>.<namespace>.<cardId>` 的线上标识。适配层双向映射；动作仍校验本人、账号、卡片版本、绝对有效期及一次性令牌。回调不从表单推断身份。

卡片增加可选 transport 字段，缺失按 legacy 解读。切换接口时旧卡服务端失效；偏好、草稿、发送记录保留，员工重新 `/dws` 即可继续处理。没有新增业务状态表。单个接口内重启保持既有卡片恢复及通知去重行为。

## 安装与开发

源码和 npm 包都可独立加载。开发依赖本项目自己的 package-lock，不依赖原目录的 node_modules。`prepare-channel.mjs` 拒绝已有目标目录，只在新克隆上应用固定补丁。通用 API 的来源、MIT 声明、补丁内容与校验值随包交付。

## 验证

自动化覆盖通用/旧桥接选择、请求失败不降级、本人回调与字段映射、迁移后旧卡拒绝、草稿和设置保留、原接口内重启恢复，以及原业务回归。真实宿主矩阵通过隔离目录加载实际安装的 SDK，模型集成使用本地夹具。

最终执行结果记录于 `../assets/standalone-validation.json`；历史 0.5–0.7 真机与性能记录单独保留，不作为本次抽离的新测试。

## 不在本次范围

不修改 OpenClaw 核心、DWS、安全插件或卡片平台模板，不实现主 Agent 全局自动回复拦截。不发布新的 GitHub 仓库，不修改或提交原社区项目。
