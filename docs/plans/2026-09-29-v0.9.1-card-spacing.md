# 0.9.1 助手卡片间距优化

日期：2026-09-29。基线：0.9.0 / `65e6328`。范围：助手各页面正文排版；不处理此前已确认与插件无关的 DWS 订阅故障。

## 需求与实现

- 同段多行文字使用紧凑换行，继续左对齐；原文空行仍表示段落。
- 标题紧接对应内容，普通分区保留一段间距，去掉各节之间重复的横线。
- 来信和将发送的回复之间保留横线；批量确认的不同回复之间也保留横线，便于核对对象与完整正文。
- 在现有 v3 的 `content_body` 中统一呈现状态、摘要、提示与正文，显式清空另三个变量，避免组件边距叠加。
- 正文先进行字面转义，再插入程序生成的 `<br>`；用户输入的 HTML、Markdown 符号仍按原文展示。字号、原生表单和按钮样式不变。
- 卡片显示编码 `cardText` 与既有 DWS 消息发送编码 `textParagraphs` 分开。来信、草稿、表单默认值、消息发送参数不因页面布局改写。

## 升级与回退

版本号为 0.9.1。无需变更配置、数据结构、Channel 或 DWS；已有 v3 模板无需重新发布或更换 ID，展示版本仍为 3。旧有效卡片继续可用，新建或刷新页面采用新排版，不触发卡片迁移。v2 纯文本呈现不变。

回退只需恢复 0.9.0 助手代码，不清理员工数据或更改模板版本。页面在下次刷新后恢复旧排版，卡片与草稿仍受原到期时间、版本和权限约束。
