## 本人可独立执行

新旧宿主串行运行，避免同一机器人并发连接。每次启动使用独立状态和临时配置，记录宿主版本、模板版本、测试编号、开始/结束时间和实际观察；结束停止隔离 Gateway 并恢复原服务。测试前后核对原配置及 Channel 文件校验值。

| 用例 | 实际操作和通过条件 |
| --- | --- |
| 模板编译 | 导入、平台预览和编译完整 v3 源码；检查四个正文分区、表单及六个动作位；发布测试模板并保存编译导出。`widgetInfo` 为空的源码不算平台编译通过。 |
| 全页面排版 | 在真实钉钉中打开首页、设置、固定回复、授权、主题、待处理、草稿/编辑、原文详情、批量预览、历史、异常和升级页；检查中文、Emoji、长正文、字面 Markdown/链接，不出现原始标记、截断发送正文或多重主按钮。 |
| 回调可见性 | 在两版宿主分别点击真实卡片的导航、保存、返回、刷新；核对界面变化及日志中同一次可信回调。只发送卡片 API 成功不算通过。 |
| 到期 | 默认 10 秒检查，用测试卡的实际到期时间观察，平台可用时到期后默认 15 秒内显示失效，按钮不可执行。核对成功失效后没有周期性重刷。 |
| 更新失败恢复 | 仅在隔离实例对卡片更新注入暂时失败，随后恢复；旧按钮可回到最新页面。实际消息已发送但刷卡失败时，重复点击不得再次发送。 |
| 普通重启 | 保持状态目录与当前模板不变重启；有效卡可继续操作，发送结果未知不重发，未完成起草显示可恢复错误。 |
| 模板迁移 | 保存旧设置、规则和有效授权，切换已预检新模板及展示版本；旧卡显示升级提示，旧发送不执行，打开新卡落到当前草稿或有效页面。重复点击/重启不重复创建新卡；入口过期引导 `/dws`。 |
| 只读 Agent | 新旧宿主都完成真实模型查询→草稿→任务清理。写文件、删文件、执行命令、浏览器、跨会话或委派诱导不能执行；没有后台发消息。超时不重复起任务，迟到输出不成为可发送草稿。 |
| 关闭工具 | 两版关闭开关继续原无工具起草，不要求专用 Agent；未配新字段的旧配置默认关闭，不影响旧设置。 |
| 存储恢复 | 在隔离状态验证过期补刷先于清理、有效卡片/未确认草稿/未知发送受保护；诊断显示行数、DB/WAL 和可复用页。清理不混同于文件压缩。 |

## 白天配合用例设计

优先请已确认的测试联系人发送，每条带不同测试编号，操作仅限本人和测试群，不向其他会话发送。

| 来信 | 预期观察 |
| --- | --- |
| 私聊，普通 AI | 展示来信、起草状态及完整草稿；只有本人确认才发送，重复点击不重复发送。 |
| 私聊，固定回复 | “逐条确认”和已有有效自动授权分别执行；授权过期停止自动发送，重叠规则冲突转人工；旧固定正文及有效授权升级后不丢失、不扩大。 |
| 主题明确命中 | 仅唯一明确命中的规则动作生效；规则版本变化不能采用旧分类结果自动发送。 |
| 未明确命中 | “其他消息照常处理”采用普通方式；“只关注指定主题”统一不处理。多命中、部分命中、识别错误/超时均不新增主题第三态，不出现无原因的“尚未生成”。 |
| 私聊连续 1～4 条 | 相邻 30 秒、单批 5 分钟边界；安静 2 秒起草、持续输入最多等 10 秒；卡片仅近三条，起草包含本批全部有效文本。 |
| 起草/编辑/发送时续发 | 迟到模型结果不覆盖新批次，未提交输入有明确处理提示，已保存人工草稿保留，发送领取后冻结，后续来信新建批次。 |
| 本人先手动回复 | 开新批次或确认发送前核实本人回复并要求重新确认，不发送过时草稿；历史关闭或不可用时不得声称已检测到本人回复。 |
| 测试群 @本人 | 历史只包含该 sender（包括未 @发言）及本人，排除其他人；不同 sender 草稿不相互替代。引用回复绑定实际目标。 |
| 历史时间和类型 | 5 分钟内双方可用文字按创建时间排列，过滤明确媒体/卡片类型、资源和媒体占位，触发消息不重复。不能识别已被接口拍平的原始类型；不读取附件。读取失败和截断有提示，0 分钟关闭历史。 |
| 批量发送 | 先看每条完整正文及收件对象，再显式最终确认；任一版本变化在首条发送前拦截，发送部分成功不重发已成功项。 |

每个大项必要真机验证完成后才做独立本地 commit。当前交付用户验收，未经另行确认不推送 GitHub。
